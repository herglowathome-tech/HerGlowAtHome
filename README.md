HerGlowAtHome website
=====================

Open index.html in a browser to preview the site.

Before publishing:
1. Replace the WhatsApp/Call buttons with HerGlowAtHome's real number.
2. Review service prices and service-area text.
3. Publish the folder on a static hosting service such as Netlify, Vercel, or GitHub Pages.

Note: The design currently uses Tailwind CSS and Google Fonts from their CDNs, so an internet connection is required for the full styling when opened.
