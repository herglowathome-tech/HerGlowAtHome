# How to add your work videos

1. Open this repository on GitHub.
2. Tap **Add file → Upload files**.
3. Upload the MP4 video inside a folder named **videos** (example: `videos/facial-result.mp4`).
4. Open `work-videos.js` and tap the pencil icon.
5. Add one line inside the square brackets:

```js
{ file: "videos/facial-result.mp4", title: "Korean Glass Facial", service: "Facial" },
```

6. Tap **Commit changes**. The video will appear at HerGlowAtHome.com/gallery.html after GitHub Pages updates.

Use short vertical MP4 videos for faster loading. Avoid spaces in filenames; use names like `party-makeup-01.mp4`.
